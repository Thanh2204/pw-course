1. git commit --amend: Thay đổi commit, lệnh này sẽ mở VIM và ta có quyền chỉnh sửa trực tiếp

2. git commit --amend -m"message": Thay đổi tên commit gần nhất thành "message"

3. git restore --staged <file>: Chuyển file từ vùng staging về woriking directory

4. git reset HEAD~1: quay về commit trước đó, đi từ repository về woking,  xóa commit mới nhất
